# Supply Chain Analytics

Portafolio de casos prácticos de **Supply Chain, Planeamiento, Inventarios y Comercio Exterior** resueltos con **SQL, Python y Power BI**.

Cada caso parte de un problema de negocio real del rubro, usa datos sintéticos y termina con hallazgos y recomendaciones accionables.

## Casos

| # | Caso | Pregunta de negocio | Estado |
|---|---|---|---|
| 01 | [Clasificación ABC-XYZ](01-abc-xyz/) | ¿Dónde concentrar el esfuerzo de planificación y cuánto capital está inmovilizado? | ✅ |
| 02 | Stock de seguridad y punto de reorden | ¿Cuánto stock necesito para un nivel de servicio objetivo? | 🔜 |
| 03 | OTIF de proveedores | ¿Qué proveedores cumplen a tiempo y completo? | 🔜 |
| 04 | Forecast de demanda | ¿Qué método pronostica mejor y con qué precisión (MAPE)? | 🔜 |
| 05 | Landed cost y tránsito Comex | ¿Cuánto cuesta realmente un producto importado puesto en almacén? | 🔜 |
| 06 | Automatización de reportes SAP | ¿Cómo eliminar horas de trabajo manual en Excel? | 🔜 |

## Estructura de cada caso
```
NN-nombre-caso/
├── README.md     problema, metodología, resultados
├── data/         raw (insumos) y processed (resultados)
├── sql/          creación de tablas y consultas
├── python/       generación de datos y análisis
├── powerbi/      guía de medidas DAX y dashboard
└── docs/         gráficos y capturas
```
